In der Minecraft-Mod

  • Rechts-Shift Saturn-Menü öffnen
  • F6 HUD-Editor (Elemente verschieben, Mausrad = Größe)
  • F7 Chat Utils (Chat durchsuchen und kopieren)
  • F8 Vanilla-HUD ein-/ausblenden

Die Saturn-Mod liegt unter ~/.saturn/instances/<profil>/mods/saturn.jar und wird beim Start jedes Fabric-Profils automatisch einsortiert - für die Minecraft-Version, für die es eine passende Mod gibt. Welche das sind, steht in mod/versions.json; läuft eine Instanz auf einer anderen Version, startet sie normal, nur eben ohne Menü.
